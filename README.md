# 💈 BarberPro - Sistema de Gestão para Barbearias

## 📋 Sobre o Projeto

O BarberPro é um sistema web desenvolvido para auxiliar no gerenciamento de barbearias, permitindo o controle de clientes, barbeiros, serviços, agendamentos e faturamento.

O objetivo do projeto é digitalizar processos que normalmente são realizados manualmente, proporcionando mais organização, produtividade e uma melhor experiência para clientes e profissionais.

---

## 🚀 Funcionalidades

### Clientes

* Cadastro de clientes
* Consulta e edição de informações
* Histórico de atendimentos

### Barbeiros

* Cadastro de barbeiros
* Controle de agenda
* Visualização de atendimentos realizados

### Serviços

* Cadastro de serviços
* Definição de preço e duração
* Gerenciamento de serviços disponíveis

### Agendamentos

* Agendamento de horários
* Reagendamento
* Cancelamento de atendimentos
* Controle de status

### Dashboard

* Agendamentos do dia
* Quantidade de clientes cadastrados
* Serviços mais realizados
* Faturamento mensal
